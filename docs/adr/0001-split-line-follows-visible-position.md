# 分割線は見えている並びの位置に置く

分割線は、特定のページではなく、見えているページ列の位置（何番目の直後か）に紐づける。手前のページを削除しても、分割線より後ろのページは後ろ側のまとまりに残す。並べ替えでは位置番号を動かさず、ページの方が切れ目をまたぐ。削除と並べ替えで位置の動かし方を同じにすると、どちらかの結果が予測しにくくなるため、この組み合わせにした。

## 検討した選択肢

- 削除後も位置番号を固定する。`1 2 | 3 4` からページ2を削除すると `1 3 | 4` になり、後ろにいたページ3が前のファイルへ移る。不採用。
- 並べ替えで、切れ目の直後にあったページに分割線を付けて動かす。ページ3を先頭へ移すと先頭の空PDFを避けるために分割線が消え、`3 1 2 4` になる。どのページをどのファイルに入れるかを並べ替えで変えられない。不採用。

## 結果

- `1 2 | 3 4` からページ2を削除すると `1 | 3 4`。
- `1 2 | 3 4` でページ3を先頭へ移すと `3 1 | 2 4`。
- 空のPDFになる分割線は取り除く。
