# 起動はフォルダ形式の1つの exe が兼ねる

配布物は、PyInstaller のフォルダ形式である。その中の 1 つの exe が、Python のバックエンド、既定ブラウザを開くこと、システムトレイの「開く」と「終了」を同じプロセスで兼ねる。1 ファイル形式は起動のたびに Temp へ展開する。PDF の作業コピーも Temp を使うので、役割が重なる。別ランチャーにすると、配布物が 2 つに分かれる。

## 検討した選択肢

- PyInstaller の 1 ファイル形式。配るファイルは 1 つになる。起動のたびに Temp へ展開するので不採用。
- トレイ専用の別ランチャーが、同梱した Python を起動する。プロセスは分かれる。配布物が 2 つになるので不採用。
- PyInstaller のフォルダ形式で、1 つの exe がバックエンドとトレイを兼ねる。採用。

## 結果

- 単一インスタンスは、Windows の名前付きミューテックスで守る。2 回目の起動は新しいバックエンドを作らず、既にあるプロセスに「開く」を渡す。
- ログイン時の自動起動はしない。
- 既定ブラウザで Web UI を開くことは変えない。
