# 表示の記憶はバックエンドのユーザー設定ファイルに置く

サムネイルの並び方とサイズ、プレビューとサムネイルの領域比率は、次回起動でも残す。仕様は Windows ユーザーごとに記憶する。画面は React だが、この値の正本はバックエンドの設定ファイルにする。Edge と Chrome で同じ値になる。

## 検討した選択肢

- ブラウザの localStorage。画面だけで完結する。ブラウザが違うと値が分かれ、仕様の Windows ユーザー単位にならないので不採用。
- 選択と表示の計画では記憶しない。その仕様が、前回の方式とサイズ、領域比率の記憶を既に求めているので不採用。
- バックエンドが `%LOCALAPPDATA%\pdf-editor\settings.json` に保存する。採用。その PC の Windows ユーザーに残る。
- `%APPDATA%`（ローミング）。別の PC へ付いていく。後から同じファイルへ入る保存先フォルダは、その PC のパスなので不採用。
- 実行ファイルの隣。インストール先や実行場所が変わると設定が分かれるので不採用。

## 結果

- ファイルは `%LOCALAPPDATA%\pdf-editor\settings.json` である。
- 選択と表示の計画で保存するのは、サムネイルの方式、サイズ、プレビューとサムネイルの領域比率である。
- ズーム倍率とページの表示位置は次回へ持ち越さない。
- 後から増える設定も、同じファイルを使う。
