# PDFの加工は pikepdf、表示は PDF.js

編集中はページ実体を書き換えず、書き出し時にページを別の PDF へコピーする。表示に必要なピクセルは、ブラウザが見ているページだけ描く。

## 検討した選択肢

- PyMuPDF で加工と描画の両方を行う。一つのライブラリで済む。ライセンスは AGPL か商用であり、ソースを非公開のまま配るかは未決なので不採用。
- pikepdf で加工し、pypdfium2 でサーバーが画像を作る。描画は許可型ライセンスでできる。プレビューのたびにサーバーが画像を作るので不採用。
- pikepdf で加工し、PDF.js でブラウザが描く。採用。

## 結果

- 加工と書き出しは pikepdf（qpdf）が行い、元ファイルとは別のパスへ保存する。
- サムネイルと大プレビューは、ブラウザ内の PDF.js が localhost のセッションコピーを読んで描く。
- 二つの実装の見た目が一致することは保証しない。ページ数とページの対応は、書き出し側の検証で確認する。
