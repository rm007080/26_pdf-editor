# Undo の1件は逆コマンドである

履歴の1件は、その操作を打ち消す逆コマンドと、操作前の選択・アクティブページの識別子である。Redo の1件は、やり直す元のコマンドと、操作後の選択である。PDF のコピーは持たない。コマンド1リクエストが、履歴の1件に対応する。

## 検討した選択肢

- 操作前のページ一覧（順番、削除、回転）と選択の写し。実装は単純になる。ページ数のたびに一覧を複製し、仕様の逆操作ともずれるので不採用。
- 逆コマンドと、操作前の選択。採用。

## 結果

- 状態が変わらない操作は履歴に入れない。
- Undo のあとで新しい編集をしたら、Redo は捨てる。
- 戻したあとの選択は、その1件が持つ識別子で復元する。
- 上限は 100 件である。超えたときは古いものから捨て、最初の破棄のときだけ通知する。
