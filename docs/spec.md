<a id="目的と利用者"></a>

## 目的と利用者

Windows の PC で、手元の PDF のページ構成を組み替え、新しい PDF として書き出す。利用するのは、その PC で編集する人である。日本語の画面だけを提供する。通信が無くても編集を完結する。

成功した状態は、元の PDF を変えずに、ページの削除、回転、並べ替え、結合、分割、選択したページの書き出しができ、書き出した PDF を開けることである。

## 提供する機能とユーザーの振る舞い

### 起動、編集タブ、終了

Windows のローカルアプリとして起動し、既定のブラウザで Web UI を開く。Microsoft Edge と Google Chrome 以外では、「このブラウザは正式な対応対象ではありません。Microsoft Edge または Google Chrome を推奨します。このまま使うこともできます。」と表示する。利用は禁止しない。編集できるタブは 1 つである。編集タブが開いているとき、2 つ目のタブには「編集画面は別のタブで開いています。このタブでは編集できません。開いているタブに戻ってください。」と表示する。

タブを閉じてもバックエンドはすぐには終了しない。システムトレイに「開く」と「終了」がある。配布物は PyInstaller のフォルダ形式で、その中の 1 つの exe が、バックエンド、既定ブラウザを開くこと、トレイを同じプロセスで兼ねる。すでに起動しているときは、新しいバックエンドを作らず、そのプロセスに「開く」を渡す。アプリ内の「終了」は、一時データを消し、バックエンドを止める。Windows へのログイン時に自動では起動しない。理由は [ADR 0008](adr/0008-one-folder-exe-owns-tray.md) にある。

操作が無い状態が続くと自動終了する。初期値は 2 時間で、設定では 30 分、1 時間、2 時間、4 時間から選ぶ。終了前に警告し、「作業を続ける」でタイマーをリセットする。クリック、キー操作、スクロール、設定の操作は対象にし、マウスを動かしただけは対象にしない。書き出しが完了するか失敗するまで、このタイマーは進めない。タブを閉じたまま書き出している間も同じである。

ブラウザだけが落ちたときは、バックエンドが生きていれば再接続して編集状態を戻す。F5 でも可能な限り戻す。バックエンド自体が異常終了したときは編集状態を戻さず、次回起動時に一時データを消して案内する。Windows のシャットダウンと再起動は妨げない。スリープは OS の設定に任せ、続けられなくなった処理は通常の失敗として扱う。

<a id="pdf-を読み込む"></a>

### PDF を読み込む

入力は PDF だけである。ファイル選択とドラッグ＆ドロップができ、複数の PDF を一度に読み込める。複数のときは、選んだ順またはドロップした順で、1 つの作業領域へページ単位で展開する。読み込み完了後は 1 ページ目を自動で選択する。

編集の途中でも末尾へ追加できる。追加後も、それまでの選択とプレビューを維持する。読み込み中は新しい追加を無効にする。キャンセルしたときは、その追加全体を取り消す。

作業領域が空の最初の読み込みも、編集途中の末尾追加も、コマンドは `append_documents` である。本文は、パスワード、電子署名、大容量、重複の確認を終えて作業領域へ入れる追加単位の識別子だけである。ファイルのバイト列とパスは含めない。バイト列は `POST /api/documents` で受け取る。この受け取りは編集状態を変えず、追加単位の識別子を返す。確認が終わるまでは、編集状態も履歴も変えない。キャンセルした追加は、`append_documents` を送らない。1 回の操作で実際に入った追加単位が、履歴の 1 件になる。取り除く逆コマンドは、同じ識別子の `remove_documents` であり、ページの削除とは別である。

開くパスワード付き PDF は、PDF ごとに順にパスワードを聞く。試行回数の上限は無い。入力は伏字で、目のアイコンで一時的に表示できる。キャンセルした PDF だけを除外し、同時に選んだ他の PDF は読み込む。

電子署名 PDF は、編集後に署名が有効でなくなる可能性を警告し、了承したものだけを作業領域へ入れる。キャンセルした PDF だけを除外する。利用制限付き PDF は、警告なしで読み込む。

大容量の確認は、追加しようとしている PDF 1 件ごとに出す。1 つの PDF が 500 ページを超える、または 100MB（100 × 1024 × 1024 バイト）を超えるときは、了承したものだけを入れる。ページ数は、開くパスワードの確認を終えたあとに数える。キャンセルした PDF だけを除外する。

同じ内容の PDF はハッシュで重複と判定し、確認して了承したときだけ追加する。同じ PDF を複数回追加したときは、追加の単位ごとに独立して管理する。

一部のページ自体が壊れて正常に処理できない PDF は、その PDF 全体を追加しない。複数のうち 1 つが失敗しても、正常な他の PDF は読み込む。失敗した PDF だけを、ファイル名と理由とともに通知する。すべて成功したときは短い成功通知にする。

<a id="ページを選び見る"></a>

### ページを選び、見る

選択は、見えているページを対象にする。0 件があり得る。単一選択、Ctrl+クリック、Shift+クリック、すべての選択ができる。Ctrl+A は、サムネイル一覧にフォーカスがあるときだけ全ページを選択する。選択中は枠または背景と、チェックマークで示す。余白のクリック、または通常状態の Esc で選択を解除する。

アクティブページは、大プレビューに表示している 1 枚である。複数選択中は、最後にクリックしたページである。選択が 0 件のときはアクティブページが無く、プレビューは空で「ページを選択してください」と表示する。このとき前へ / 次へは無効で、ページ移動の矢印キーも Shift+矢印もページを選ばない。

アクティブページがあるときの前へ / 次へ、および ← / → は、複数選択を解除して移動先の 1 ページを選択する。サムネイル一覧では ← / →、複数列では ↑ / ↓ でも移動する。Shift+矢印は連続範囲を拡張または縮小する。入力欄などにフォーカスがあるときは、その欄の標準の操作を優先する。

サムネイルは「横一列と横スクロール」と「複数列と縦スクロール」を切り替えられ、サイズは小 / 中 / 大である。枠の高さは小 96px、中 150px、大 220px で、幅はページの縦横比に合わせる。前回の方式とサイズを記憶する。初回は横一列、中である。各サムネイルに、現在ページ番号、元 PDF 名、元ページ番号を示す。長い名前は省略し、ホバーで全文を出す。フルパスは通常は出さない。右クリックメニューと、ダブルクリックの特別な動作は無い。

大プレビューは編集画面の中に常にある。表示モードは、ページ全体、幅に合わせる、100% で、初期はページ全体である。+/- と Ctrl+ホイールの段階は、25% から 400% まで 25 ポイント刻みである。ページ全体の倍率が 25% 未満のときはその倍率のままにし、+/- で段階へ移ったときだけ 25% 以上になる。拡大時はスクロールバーとドラッグでパンする。ページを切り替えても、倍率、表示モード、ページ内の相対位置を可能な限り維持する。全画面プレビューは無い。ズームは次回起動へ持ち越さない。

ページ番号の指定でジャンプできる。範囲外はエラーになる。Enter でも実行し、成功したら入力欄を空にする。画面には、総ページ数、選択ページ数、元 PDF 数を出す。Tab で主要な要素へ移動でき、フォーカスを分かるように示す。プレビューとサムネイルの境界はドラッグで高さ調整でき、前回の比率を記憶する。最低高さは、大プレビューが 240px、サムネイル領域が 160px である。記憶が無いあいだは、サムネイル領域を現在のサイズの 1 行分にし、残りを大プレビューにする。横一列のサムネイルでは、通常のホイールで左右にスクロールする。サムネイルは、表示枠の CSS ピクセルに devicePixelRatio を掛けて描き、長辺の上限は 400px である。見えていないサムネイルにはキャンバスを作らない。大プレビューのビットマップは、現在のページと前後 1 ページの最大 3 枚である。

<a id="回転削除並べ替え"></a>

### 回転、削除、並べ替え

回転は左 90 度または右 90 度で、角度は 0 / 90 / 180 / 270 度として持つ。サムネイル上の回転と削除は、そのページだけに効く。選択全体の回転と削除は上部ツールバーで行う。回転後も選択は維持する。

削除に毎回の確認は無い。直後に「○ページを削除しました」と「元に戻す」を出す。見えているページが 0 枚になるまで削除できる。0 枚のときは書き出せない。削除してもページの識別子は残り、見えている並びから外れる。元の PDF のページ実体は、この時点では変えない。

サムネイルで 1 枚だけ削除し、他の選択が残るときは、消していないページの選択を残す。削除したページがアクティブページでなければ、アクティブページも残す。例: ページ 2 と 5 が選択でアクティブが 5 のとき、ページ 2 を消してもページ 5 の選択とアクティブは残る。アクティブページ自身を消し、選択が 2 件以上残るときは、削除した位置より後ろで最も近い残りの選択を新しいアクティブページにする。後ろが無ければ直前の選択である。残る選択が 1 件ならそのページ、0 件ならアクティブページは無い。

それまで選ばれていたページが残らない削除のあとは、削除位置に来たページを選択する。末尾を削除したときは前のページを選択する。ページが 1 枚も残らなければ選択は 0 件である。上部ツールバーの削除は選択全体が対象なので、この規則に入る。

並べ替えはドラッグ＆ドロップである。選択中のページをドラッグすると選択全体が動く。未選択のページをドラッグすると、既存の選択を解除してそのページだけが動く。挿入位置をその場で示し、移動後も選択を維持する。Esc でドラッグを取り消す。横一列では左右の端、複数列では上下の端で、480px/秒の一定速度で自動スクロールをする。ドラッグを開始する距離は 8px である。状態が変わらない移動は通知し、Undo の履歴には入れない。現在ページ番号を使い、指定したページの前または後へ移動できる。独自のキーボード並べ替えショートカットは設けない。

### 分割線

分割線は、隣り合うサムネイルの間をクリックして入れる。複数列のときも、現在ページ番号で隣り合う境目（行の末尾と次の行の先頭のあいだを含む）をクリックする。同じ位置をもう一度クリックすると、その分割線を解除する。「すべての分割線を解除」は、それとは別の 1 操作である。

分割線はページではなく、見えている並びの位置に紐づく。`1 2 | 3 4` からページ 2 を削除すると `1 | 3 4` になる。ページ 3 を先頭へ移すと `3 1 | 2 4` になる。空の PDF になる分割線は取り除く。詳細は [ADR 0001](adr/0001-split-line-follows-visible-position.md) に従う。

1 本を入れるコマンドは `set_split`、1 本を外すコマンドは `clear_split` である。どちらも、見えている並びでその線の直前にあるページの識別子で境目を指定する。クリックは、入っていなければ `set_split`、入っていれば `clear_split` を送る。すでにその状態なら履歴に入れない。「すべての分割線を解除」は `clear_all_splits` で、識別子は持たない。その Undo は、解除した境目の直前ページの識別子を並べた 1 件の `set_split` である。画面から複数本を一度に入れる操作は無い。

<a id="書き出す"></a>

### 書き出す

書き出しは 3 種類である。全ページを 1 つの PDF にする操作を主ボタンにし、分割と選択ページはその隣のメニューに置く。

- 全ページ: 見えているページを 1 つの PDF にする。元 PDF が 1 つなら、初期ファイル名は `元ファイル名_編集済み.pdf` である。2 つ以上なら、ページが残っている元 PDF のうち最初に追加したもののファイル名に `_編集済み.pdf` を付ける。並べ替えではこの名前は変わらない。
- 選択ページ: 見えている並びの順で出力する。クリックした順では出さない。選択が 0 件のときは無効である。初期ファイル名は、今回の書き出しに含まれる元 PDF のうち、最初に追加したもののファイル名に `_編集済み.pdf` を付けたものである。
- 分割: 分割線で分かれたまとまりごとに PDF にする。初期ファイル名は `名前_1.pdf`、`名前_2.pdf` である。ベースの名前は、ページが残っている元 PDF のうち最初に追加したものである。番号は 1 から、見えている並びの前のまとまり順である。各名前は個別に変更できる。保存先フォルダは 1 回指定する。

同名のファイルは上書きせず、`(1)`、`(2)` を付けて避ける。保存ダイアログ、保存した PDF を開く操作、保存先のフォルダを開く操作は、バックエンドが Windows へ依頼する。前回の保存先を記憶する。前回が無いとき、またはその場所が使えないときは、その Windows ユーザーのドキュメント フォルダをダイアログの初期フォルダにする。使えない前回の場所から切り替えたときは通知する。

書き出し前に空き容量を確認する。最終のファイル名へ直接書かず、一時ファイルへ作り、PDF として開けることと、予定のページ数と一致することを確認してから確定する。失敗またはキャンセルのときは、不完全なファイルを可能な限り消し、編集状態は残す。書き出し中は編集をロックし、進捗率、処理したページ数、処理の段階を表示する。残り時間の予測は出さない。保存に成功したあとも編集状態は残し、ファイル名、保存先、「PDF を開く」、「保存先を開く」を表示する。

全ページの書き出しが正常に終わったときだけ、その状態を新しい保存済みの基準にする。選択ページと分割の書き出しでは、通常の未保存は解除しない。

<a id="元に戻す"></a>

### 元に戻す

削除、回転、並べ替え、PDF の追加と取り除き、分割線などを Undo / Redo の対象にする。ユーザーが 1 回行った操作を 1 単位とし、複数ページの一括操作も 1 回とする。実際に状態が変わった操作だけを履歴へ入れる。Undo のあとで新しく編集したら、Redo の履歴を捨てる。履歴の一覧から任意の時点へ飛ぶ機能は無い。書き出したあとも履歴は残す。

Undo / Redo のあと、選択と見ている位置を可能な限り維持し、同じページを識別子で追う。実行できない Undo / Redo は無効にし、ホバーまたはフォーカスで理由と、次に何が起きるかを示す。

### 未保存と分割設定

未保存かどうかは、操作した回数ではなく、現在の出力状態で判断する。1 つの PDF を読み込んだだけなら、原本の状態を保存済み相当の基準にする。複数 PDF の初回読み込み、PDF の追加、回転、削除、並べ替えなどで基準と違えば未保存である。Undo などで基準と完全に一致すれば、未保存は自動で解ける。

分割線は、この未保存判定には入れない。別に「分割設定 未出力」を管理する。分割結果に影響する編集のあと、再び未出力にする。画面には必要なときだけ「未保存」と「分割設定 未出力」を出し、クリックで対応する書き出しへ進む。

終了または「新しく始める」のとき、失われる状態が複数あれば 1 つの確認にまとめる。失われるものが無ければ確認しない。

### 設定、ヘルプ、通知

上部に「PDF 編集」「設定」「ヘルプ」がある。設定は独立したページで、変更はすぐ反映され、自動で保存される。ブラウザの戻る / 進むにも対応する。設定またはヘルプから戻っても、選択、倍率、スクロール位置を可能な限り維持する。

テーマはライトとダークである。一度も選んでいないあいだは、Windows のアプリの色に合わせる。ユーザーが切り替えたあとだけ、その選択を記憶し、以後は Windows の色が変わっても追従しない。「設定を初期状態に戻す」は確認のあと実行し、テーマの記憶も消して、再び Windows のアプリの色に合わせる。

設定は Windows ユーザーごとに保存する。ファイルは `%LOCALAPPDATA%\pdf-editor\settings.json` で、バックエンドが読み書きする。サムネイルのサイズ、表示方式、プレビューとサムネイルの領域比率、前回の読み込みフォルダと保存フォルダを記憶する。最近使った PDF の名前とパスの履歴は残さない。ズーム倍率とページの表示位置は次回へ持ち越さない。

ヘルプは、基本操作、複数選択、分割、ショートカットを文章と簡単な図で説明する。検索は無い。設定の下部に、アプリ名、バージョン、「更新を確認」を出す。設定には「エラーログの保存先を開く」がある。技術ログは 30 日、または合計 10MB（10 × 1024 × 1024 バイト）を超えたとき、古いものから、両方の上限に収まるまで消す。開発者向けの API ドキュメントは開発版だけで有効にし、完成版では無効にする。上部の操作が幅に収まっているあいだは、アイコンと文字を出す。収まらなくなったら、先に文字を隠してアイコンだけにする。まだ収まらなければ、次の順で「...」へしまう。先のものからしまう。終了、新しく始める、サムネイルの並びとサイズ、すべての分割線を解除、やり直す、元に戻す、左回転、右回転、削除。書き出し（全ページと、その隣の分割・選択ページ）、「PDF 編集」「設定」「ヘルプ」、前へ / 次へ、ズームはしまわない。余白の単位は 8px である。画面の端は 16px、隣り合う操作の間隔は 8px である。ツールバーのアイコンは 20px である。周囲の余白を含め、押せる範囲は 1 辺 36px である。操作名と本文は 14px、サムネイルの元 PDF 名や補足は 12px である。削除、破棄、終了などは、警告の色またはアイコンで区別する。

通常の成功通知は数秒で消える。エラーと重要な警告は、ユーザーが閉じるまで残る。バックグラウンド処理の完了と失敗は Windows 通知にする。通知に機密は出さない。Windows 通知は設定でオン / オフでき、初期値はオンである。

更新確認は、ユーザーが「更新を確認」を押したときだけ行う。最新版があるかどうかの通知までで、自動のダウンロードとインストールはしない。

## 要求ごとの受け入れ条件

### 起動と終了

- アプリは Windows 上で、既定ブラウザの Web UI と Python バックエンドとして動く。待ち受けるのは localhost / 127.0.0.1 だけで、他の PC からは使えない。
- 配布物は PyInstaller のフォルダ形式である。1 つの exe が、バックエンド、既定ブラウザを開くこと、トレイの「開く」と「終了」を同じプロセスで兼ねる。2 回目の起動は、既にあるプロセスに「開く」を渡す。
- 正式に対応するのは Microsoft Edge と Google Chrome である。それ以外では「このブラウザは正式な対応対象ではありません。Microsoft Edge または Google Chrome を推奨します。このまま使うこともできます。」と表示する。利用は禁止しない。
- 編集タブは 1 つである。2 つ目のタブは、上記の案内文を表示し、編集できない。
- スマホとタブレットは対象外である。Windows の表示倍率 100% / 125% / 150% などで、ノート PC からワイドモニターまで使える。
- タブを閉じてもバックエンドは即終了しない。再起動時は、生きているバックエンドへ接続する。
- 自動終了の初期値は 2 時間である。書き出しの完了または失敗までタイマーは進まない。
- アプリ内の終了と、自動終了と、「新しく始める」は、一時データを消す。異常終了の残骸は次回起動時に消す。Windows のシャットダウンと再起動は妨げない。

### 読み込み

- PDF 以外は読み込まない。複数 PDF は選択順またはドロップ順で、1 つの作業領域のページになる。
- 成功した読み込みは、Windows Temp 配下の専用領域へセッション用コピーを作り、以後はそのコピーを使う。元 PDF はロックしない。元 PDF が移動、削除、外部から変更されても、セッションは続く。
- 共有上の PDF も、Windows から通常どおり開けるなら読み込める。コピーの途中で切れたら失敗とし、不完全なコピーを消し、自動では再開しない。
- 開くパスワードをキャンセルした PDF、電子署名の警告をキャンセルした PDF、および大容量の確認をキャンセルした PDF だけを除外する。利用制限付き PDF は、利用制限そのものでは警告しない。
- 大容量の確認は PDF 1 件ごとである。500 ページを超える、または 100MB（100 × 1024 × 1024 バイト）を超えるときに出し、了承したものだけを入れる。ページ数は、開くパスワードの確認のあとに数える。
- パスワードはログと設定に保存しない。
- 内容が壊れて処理できない PDF は、そのファイル全体を追加しない。他の正常な PDF は読み込む。
- 同じ内容の PDF は確認し、了承したときだけ追加する。編集の途中の追加は末尾になり、それまでの選択とプレビューを維持する。読み込み中の追加はできず、キャンセルした追加は全体を取り消す。
- 空の作業領域への読み込みも、編集途中の末尾追加も `append_documents` である。本文は追加単位の識別子だけである。バイト列は `POST /api/documents` で受け取り、この受け取りだけでは編集状態を変えない。キャンセルした追加は `append_documents` を送らず、編集状態を変えない。`remove_documents` は、その追加単位を外す。ページの削除とは別である。

### 選択、プレビュー、キーボード

- 選択が 0 件のとき、プレビューは空で、前へ / 次へも矢印キーもページを選ばない。
- アクティブページがあるときのページ移動は、移動先 1 ページだけの選択になる。
- サムネイルの回転と削除は、その 1 ページだけに効く。選択全体の回転と削除は上部ツールバーである。
- サムネイルからアクティブページを削除し、選択が 2 件以上残るときは、後ろで最も近い残りの選択、無ければ直前が新しいアクティブページになる。
- 選ばれていたページが残らない削除のあとは、削除位置に来たページ、末尾なら前のページを選択する。
- ページの切り替え後も、倍率、表示モード、ページ内の相対位置を可能な限り維持する。回転後も、見ていた内容の付近が残るよう補正する。
- 無効なボタンは、理由と使える条件をツールチップで示す。Delete、Ctrl+A、Ctrl+Z / Y、矢印キーは、入力欄の標準操作を壊さない。

<a id="編集状態"></a>

### 編集状態

- 各ページは、非表示の一意な識別子、元 PDF の追加単位、元ページ番号、現在の順、削除状態、回転状態を持つ。
- 削除、回転、並べ替えは元ページをその場で書き換えず、書き出し時に反映する。
- 可能な処理では、ページを画像化せず PDF のページとして扱う。勝手な再圧縮をせず、ページサイズを維持する。メタデータは積極的には引き継がない。しおりは引き継がない。PDF 内のリンクの維持は保証しない。

### 分割線

- 分割線の設定と解除は、隣り合うサムネイルの間のクリックで行う。
- `1 2 | 3 4` からページ 2 を削除すると `1 | 3 4`、ページ 3 を先頭へ移すと `3 1 | 2 4` になる。空の PDF になる分割線は取り除く。
- 分割線の操作と、「すべての分割線を解除」は Undo / Redo の対象である。後者は 1 操作である。
- `set_split` と `clear_split` は、直前ページの識別子で 1 本の境目を指定する。`clear_all_splits` は識別子を持たない。解除した複数本を元に戻す Undo は、1 件の `set_split` である。

### 書き出し

- 3 種類の初期ファイル名は、前節の規則と一致する。保存ダイアログ、PDF を開く、保存先を開くは、バックエンドが Windows へ依頼する。前回の保存先が無い、または使えないときは、ドキュメント フォルダを初期フォルダにし、使えない前回の場所から切り替えたときは通知する。
- 書き出し中は編集をロックし、進捗率、処理したページ数、処理の段階を表示する。残り時間は出さない。
- 選択ページは現在の文書順で、未選択時は実行できない。見えているページが 0 枚のときも書き出せない。
- 書き出しは一時ファイルを作り、PDF として開けることと予定ページ数の一致を確認してから最終の名前にする。
- 失敗、キャンセル、共有への保存失敗では、不完全なファイルを可能な限り消し、自動では再送しない。編集状態は残る。
- 共有への保存も、一時ファイル、検証、最終的なリネームの順である。共有のフルパスはエラーログへ記録しない。
- 保存成功後も編集状態が残り、ファイル名と保存先と、PDF および保存先を開く操作が表示される。
- 全ページの正常な書き出しだけが、未保存の基準を更新する。

### 未保存、Undo、設定

- 未保存と「分割設定 未出力」は、この仕様の定義どおりに付いたり消えたりする。
- Undo は軽量な逆操作の情報を保持し、PDF 本体のコピーを履歴の単位にしない。上限は 100 件である。超えたときは古いものから捨て、最初の破棄のときだけ通知する。
- 設定の変更は即時に保存される。初期化は確認後に、テーマを未選択の状態へ戻す。
- 完成版の技術ログに、PDF 本文、パスワード、ファイル名、フルパス、共有サーバー名を含めない。開発版は詳細なエラーを表示し、完成版は利用者向けのメッセージだけを表示する。
- 技術ログは 30 日、または合計 10MB（10 × 1024 × 1024 バイト）を超えたとき、古いものから、両方の上限に収まるまで消す。

## 制約と対象外

- 元 PDF は変更しない。完成物は新しい PDF である。
- PDF の本文、サムネイル、ファイル名、パスワード、編集内容を外部へ送らない。
- 失敗またはキャンセルした不完全な PDF を、完成品として残さない。
- 数百ページ、将来的には 500 ページ級を想定する。必要な部分を必要なときに読み、プレビューのキャッシュには上限を付ける。PC 全体のメモリを監視する機能は設けない。
- 確認ダイアログは、未保存の破棄、設定の初期化、重複 PDF、大容量 PDF、電子署名など、意味のある場面に限る。
- 対象外: PDF 本文への文字、図形、マーカーの追加、OCR、トリミング、印刷、画像 / Word / Excel への変換、ページサイズの統一、ページの複製、逆順、しおりとメタデータの編集、書き出し PDF への新しいパスワード。
