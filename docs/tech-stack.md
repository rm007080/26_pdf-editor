# PDF編集 技術スタック

文書状態: 下書き

要件で言語と実行形態は合意している。Web フレームワーク、画面、PDF の加工と表示、保存ダイアログの担い手は選定済みである。パッケージングは未選定である。リポジトリに依存関係の設定ファイルは無い。正確な導入バージョンは、設定ファイルができたあとにそこを参照する。この文書は実装準備の完了を意味しない。

要求は [仕様](spec.md)、構成は [アーキテクチャ](architecture.md) に従う。

## 採用

まだ導入は確認していない。採用理由は各行に書いた。状態列が、決定済みか、要件上の対応ブラウザのように下限未定かを示す。

| 技術 | 用途 | 採用理由 | 状態 | 参照 |
| --- | --- | --- | --- | --- |
| Python 3.11 以上 | バックエンド。編集状態、読み込み、書き出し、自動終了 | 要件が Python バックエンドを指定している。開発機の `python` は 3.11.9 | 採用決定。設定ファイルは無く、パッケージの厳密な版は未導入 | [要件定義書](../reference/PDF_Editor_要件定義書.md) のアプリ構成、自動終了 |
| FastAPI | ローカル API と画面の配信。開発版だけの API ドキュメント | 仕様が開発版だけ API ドキュメントを有効にすることを求め、要件定義書が例として挙げている | 採用決定。未導入 | [アーキテクチャの構成要素と役割](architecture.md#構成要素と役割) |
| uvicorn | `python -m app` から起動する開発用の ASGI サーバー | FastAPI を 127.0.0.1 で待ち受けるため | 採用決定。未導入 | 同上 |
| Vite | 画面の組み立て。できたファイルを FastAPI が配信する | 実行中の受付を Python に残す。理由は [ADR 0003](adr/0003-screen-uses-react.md) | 採用決定。未導入 | [ADR 0003](adr/0003-screen-uses-react.md) |
| React | サムネイル、大プレビュー、書き出し表示を、Python の編集状態に合わせて更新する | 一つの操作で複数の表示が変わる。ページの順番、削除、回転の正本は Python である | 採用決定。未導入 | [ADR 0003](adr/0003-screen-uses-react.md) |
| TypeScript | 画面が受け取るページ記録の形を、実行前に確認する | 識別子、順番、回転、進捗の形が画面と API でずれるのを、起動前に見つける | 採用決定。未導入 | [ADR 0003](adr/0003-screen-uses-react.md) |
| Node.js | 画面の組み立てだけに使う。アプリの実行時には使わない | Vite が画面を組み立てるため。開発機は v24.15.0。厳密な版は package.json 導入後にそこを参照する | 採用決定。未導入 | [ADR 0003](adr/0003-screen-uses-react.md) |
| PDF.js | サムネイルと大プレビューの描画。`pdfjs-dist` を画面の組み立てに含める | 見ているページだけを localhost 上で描く。理由は [ADR 0002](adr/0002-pikepdf-and-pdfjs.md) | 採用決定。未導入。版は `web/package.json` 導入後にそこを参照する | [ADR 0002](adr/0002-pikepdf-and-pdfjs.md) |
| pikepdf | 読み込み、ページのコピー、書き出し | qpdf がページを別ファイルへコピーする。元ファイルは書き換えない。理由は ADR 0002 | 採用決定。未導入 | [ADR 0002](adr/0002-pikepdf-and-pdfjs.md) |
| Web UI と既定ブラウザ | 編集画面を既定ブラウザで開く | ローカル Web サーバーと既定ブラウザで起動することが合意されている | 採用決定。未導入 | [要件定義書](../reference/PDF_Editor_要件定義書.md) のアプリ構成 |
| Microsoft Edge、Google Chrome | 正式に対応するブラウザ | 要件がこの 2 つを正式対応としている。それ以外は警告し、利用は禁止しない | 採用予定。バージョンの下限は未定 | 同上 |
| Windows | 対象 OS。Temp、ドキュメント、システムトレイ、通知。保存ダイアログはバックエンドが ctypes で出す | 対象が Windows 向けローカルアプリである。保存先の実パスを書き出しが持つ | 採用決定。ダイアログは未導入 | [仕様の書き出す](spec.md#書き出す) |
| localhost / 127.0.0.1 | ブラウザとバックエンドの通信。起動ごとの一時トークンを Bearer で要求する | 他の PC から使えないことが合意されている | 採用決定。未導入 | [アーキテクチャの接続とデータの扱い](architecture.md#接続とデータの扱い) |
