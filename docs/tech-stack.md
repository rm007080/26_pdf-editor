# PDF編集 技術スタック

文書状態: 下書き

要件で言語と実行形態は合意している。Web フレームワーク、画面、PDF の加工と表示、保存ダイアログの担い手、パッケージングは選定済みである。依存関係の設定は `pyproject.toml` と `web/package.json` にある。正確な導入バージョンは、そこを参照する。この文書は製品全体の完成を意味しない。

要求は [仕様](spec.md)、構成は [アーキテクチャ](architecture.md) に従う。

## 採用

採用理由は各行に書いた。状態列が、導入済みか、要件上の対応ブラウザのように下限未定かを示す。正確な版は設定ファイルを参照する。

| 技術 | 用途 | 採用理由 | 状態 | 参照 |
| --- | --- | --- | --- | --- |
| Python 3.11 以上 | バックエンド。編集状態、読み込み、書き出し、自動終了 | 要件が Python バックエンドを指定している。開発機の `python` は 3.11.9 | 導入済み。厳密な版は `pyproject.toml` | [要件定義書](../reference/PDF_Editor_要件定義書.md) のアプリ構成、自動終了 |
| FastAPI | ローカル API と画面の配信。開発版だけの API ドキュメント | 仕様が開発版だけ API ドキュメントを有効にすることを求め、要件定義書が例として挙げている | 導入済み。版は `pyproject.toml` | [アーキテクチャの構成要素と役割](architecture.md#構成要素と役割) |
| uvicorn | `python -m app` から起動する開発用の ASGI サーバー | FastAPI を 127.0.0.1 で待ち受けるため | 導入済み。版は `pyproject.toml` | 同上 |
| Vite | 画面の組み立て。できたファイルを FastAPI が配信する | 実行中の受付を Python に残す。理由は [ADR 0003](adr/0003-screen-uses-react.md) | 導入済み。版は `web/package.json` | [ADR 0003](adr/0003-screen-uses-react.md) |
| React | サムネイル、大プレビュー、書き出し表示を、Python の編集状態に合わせて更新する | 一つの操作で複数の表示が変わる。ページの順番、削除、回転の正本は Python である | 導入済み。版は `web/package.json` | [ADR 0003](adr/0003-screen-uses-react.md) |
| TypeScript | 画面が受け取るページ記録の形を、実行前に確認する | 識別子、順番、回転、進捗の形が画面と API でずれるのを、起動前に見つける | 導入済み。版は `web/package.json` | [ADR 0003](adr/0003-screen-uses-react.md) |
| Node.js | 画面の組み立てだけに使う。アプリの実行時には使わない | Vite が画面を組み立てるため。開発機は v24.15.0。厳密な版は `web/package.json` を参照する | 組み立てに使用。実行時には使わない | [ADR 0003](adr/0003-screen-uses-react.md) |
| PDF.js | サムネイルと大プレビューの描画。`pdfjs-dist` を画面の組み立てに含める | 見ているページだけを localhost 上で描く。理由は [ADR 0002](adr/0002-pikepdf-and-pdfjs.md) | 導入済み。版は `web/package.json` | [ADR 0002](adr/0002-pikepdf-and-pdfjs.md) |
| pikepdf | 読み込み、ページのコピー、書き出し | qpdf がページを別ファイルへコピーする。元ファイルは書き換えない。理由は ADR 0002 | 導入済み。版は `pyproject.toml` | [ADR 0002](adr/0002-pikepdf-and-pdfjs.md) |
| Web UI と既定ブラウザ | 編集画面を既定ブラウザで開く | ローカル Web サーバーと既定ブラウザで起動することが合意されている | 画面の配信は確認済み。既定ブラウザを開く経路は未確認 | [要件定義書](../reference/PDF_Editor_要件定義書.md) のアプリ構成 |
| Microsoft Edge、Google Chrome | 正式に対応するブラウザ | 要件がこの 2 つを正式対応としている。それ以外は警告し、利用は禁止しない | 採用予定。バージョンの下限は未定 | 同上 |
| Windows | 対象 OS。Temp、ドキュメント、システムトレイ、通知。保存ダイアログはバックエンドが ctypes で出す | 対象が Windows 向けローカルアプリである。保存先の実パスを書き出しが持つ | 保存ダイアログのコードは導入済み。実ダイアログの人手確認とトレイは未了 | [仕様の書き出す](spec.md#書き出す) |
| localhost / 127.0.0.1 | ブラウザとバックエンドの通信。起動ごとの一時トークンを Bearer で要求する | 他の PC から使えないことが合意されている | 導入済み。待ち受け先の設定はテストが 127.0.0.1 であることを確認した | [アーキテクチャの接続とデータの扱い](architecture.md#接続とデータの扱い) |
| PyInstaller | フォルダ形式の exe。1 つの exe がバックエンド、既定ブラウザを開くこと、トレイを兼ねる | 1 ファイル形式は起動のたびに Temp へ展開し、PDF の作業コピーと役割が重なる。別ランチャーは配布物が 2 つになる。理由は [ADR 0008](adr/0008-one-folder-exe-owns-tray.md) | 選定済み。未実装 | [ADR 0008](adr/0008-one-folder-exe-owns-tray.md) |
