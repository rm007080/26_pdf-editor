# PDF編集 技術スタック

文書状態: 下書き

要件で言語と実行形態は合意している。フレームワーク、PDF 処理、パッケージングは未選定である。リポジトリに依存関係の設定ファイルは無い。正確な導入バージョンは、設定ファイルができたあとにそこを参照する。この文書は実装準備の完了を意味しない。

要求は [仕様](spec.md)、構成は [アーキテクチャ](architecture.md) に従う。

## 採用予定

まだ導入は確認していない。選定理由は、要件定義でその技術の役割が合意されていることである。

| 技術 | 用途 | 採用理由 | 状態 | 参照 |
| --- | --- | --- | --- | --- |
| Python | バックエンド。編集状態、読み込み、書き出し、自動終了 | 要件が Python バックエンドを指定している | 採用予定。設定ファイルは無く、バージョンは未定 | [要件定義書](../reference/PDF_Editor_要件定義書.md) のアプリ構成、自動終了 |
| Web UI と既定ブラウザ | 編集画面、設定、ヘルプ | ローカル Web サーバーと既定ブラウザで起動することが合意されている | 採用予定。フロントエンドのフレームワークは未選定 | 同上 |
| Microsoft Edge、Google Chrome | 正式に対応するブラウザ | 要件がこの 2 つを正式対応としている。それ以外は警告し、利用は禁止しない | 採用予定。バージョンの下限は未定 | 同上 |
| Windows | 対象 OS。Temp、ドキュメント、システムトレイ、通知 | 対象が Windows 向けローカルアプリである | 採用予定 | [仕様の目的と利用者](spec.md#目的と利用者) |
| localhost / 127.0.0.1 | ブラウザとバックエンドの通信 | 他の PC から使えないことが合意されている | 採用予定。HTTP サーバーの実装は未選定 | [アーキテクチャの接続とデータの扱い](architecture.md#接続とデータの扱い) |
