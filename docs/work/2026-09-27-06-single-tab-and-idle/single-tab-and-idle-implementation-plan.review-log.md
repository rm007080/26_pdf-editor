- 担当: サブエージェント計画レビュー（generalPurpose / inherit）

### 指摘と対応

| 重大度 | 指摘 | 対応 |
| --- | --- | --- |
| P1 | `sendBeacon` は Bearer を付けられず、`require_bearer` で release が失敗する | ✅ v2。`pagehide` の `fetch`（`keepalive` と Bearer）に固定。Beacon は使わない。他人の `tab_id` の release は手放さない |
| P1 | 無操作中に `idle_warning` を画面が観測する手段が無い | ✅ v2。heartbeat 応答に `idle_warning` を含め、編集権タブはそれで警告を出す。セッション応答にも残す |
| P1 | 待機タブの再 claim 間隔と、成功後のセッション取得が無い | ✅ v2。2 秒ごとに再 claim し、成功後に `GET /api/session` で編集画面へ切り替える |
| P1 | 終了確認のチェックが未保存だけで、`split_unexported` のみ真が抜ける | ✅ v2。両方偽なら確認なし。どちらかが真のキャンセルは停止しない。実行時は停止する |
| P1 | 編集権が無いときの 409 対象が一部 API に偏る | ✅ v2。`claim` / `release` / `heartbeat` 以外の `/api/` は 409。ファイル取得と設定を含む |
| P1 | 設定 GET の 409 を、アーキテクチャの設定の口へ書くタスクが無い | ✅ v2。忙しいときの拒否しない文を、編集権があるタブに限る 2 文へ置き換えるタスクを同期状況へ書いた |
| P2 | 無操作の起算点が未記載 | ✅ v2。`startup` の直後から。編集権が無くても進む |
| P2 | 警告へ足す未保存／未出力の文面が未固定 | ✅ v2。仕様の確認文から問いかけを除いた 3 通りを固定 |
| P2 | 背面タブで heartbeat が間引かれる | ✅ v2。隠れているあいだの 5 秒途絶は仕様どおり失う。見えた直後に heartbeat し、失敗なら同じ `tab_id` で claim し直す |
| P2 | 既存 API テストが claim なしでセッションを読む | ✅ v2。同一 `tab_id` の claim を共通セットアップに含める |
