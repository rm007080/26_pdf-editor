## フェーズ1: 選択をセッションに載せる

編集状態の正本は Python バックエンドが持つ。選択はページの削除状態や回転には入れない。

### 実装

- [x] `GET /api/session` の応答に `selected_page_ids` と `active_page_id` を加える
- [x] 成功した GET と PATCH の `selected_page_ids` は、サーバが見えている順（現在ページ番号の昇順）へ並べ替えて返す。クリック順にはしない
- [x] PATCH 本体の並びが違っても 400 にはしない
- [x] 選択が 0 件のとき `selected_page_ids` は `[]`、`active_page_id` は null である
- [x] 読み込み成功時は、見えている 1 ページ目を選択し、それをアクティブページにする
- [x] 作業領域を置き換えたときも、見えている 1 ページ目を選択し、それをアクティブページにする
- [x] ページが 0 枚のときは、選択 0 件、アクティブページ無しである
- [x] `PATCH /api/session/selection` を追加する。本体は `selected_page_ids` と `active_page_id` である。成功でセッションを返す
- [x] アクティブページが選択に含まれないときは 400 とし、セッションを変えない
- [x] 見えていないページを含むときは 400 とし、セッションを変えない
- [x] 未知の識別子を含むときは 400 とし、セッションを変えない
- [x] 識別子が重複するときは 400 とし、セッションを変えない
- [x] 空の選択は `selected_page_ids: []` かつ `active_page_id: null` だけを成功とする
- [x] 読み込み中、ダイアログ中、書き出し中の PATCH は 409 とし、セッションを変えない
- [x] この PATCH は Undo の履歴を作らない。履歴そのものは次の計画である
- [x] トークンの無い PATCH は拒否する
- [x] `tests/test_session.py` に、上記の成功と失敗を足す
- [x] 既存の `test_empty_session` の厳密一致へ `selected_page_ids: []` と `active_page_id: null` を含める
- [x] `test_load_records_pages_and_leaves_original_unchanged` は、見えている 1 ページ目の `id` だけが選択され、それが `active_page_id` であることを確認する
- [x] `test_second_success_replaces_previous_copy` は、見えている 1 ページ目の `id` だけが選択され、それが `active_page_id` であることを確認する

## フェーズ3: サムネイルの並びと、表示の記憶

### 実装

- [x] サムネイルは「横一列と横スクロール」と「複数列と縦スクロール」を切り替える
- [x] 枠の高さは小 96px、中 150px、大 220px とする
- [x] 幅はページの縦横比に合わせる
- [x] 各サムネイルに、現在ページ番号、元 PDF 名、元ページ番号を示す
- [x] 長い名前は省略し、ホバーで全文を出す
- [x] フルパスは出さない
- [x] 右クリックメニューと、ダブルクリックの特別な動作は無い
- [x] 横一列では、通常のホイールで左右にスクロールする
- [x] 見えていないサムネイルにはキャンバスを作らない
- [x] サムネイルのキャンバスは、表示枠の CSS ピクセルに devicePixelRatio を掛けて描く
- [x] サムネイルのキャンバスの長辺の上限は 400px である
- [x] 現行の `paintFittedPage`（`web/src/pdf.ts`。プレビューとサムネイルが共用するフィット描画）は、ズームや長辺上限のために書き換えない
- [x] サムネイル用の描画を別にし、大プレビューのズーム、パン、3 枚キャッシュも別関数にする
- [x] 大プレビューのビットマップは、現在のページと前後 1 ページの最大 3 枚まで保持する
- [x] プレビューとサムネイルの境界をドラッグで調整する
- [x] 最低高さは、大プレビュー 240px、サムネイル領域 160px である
- [x] 設定ファイルは `%LOCALAPPDATA%\pdf-editor\settings.json` とし、バックエンドが読み書きする
- [x] ブラウザの localStorage は使わない
- [x] 保存するのは、サムネイルの方式、サイズ、領域比率だけである
- [x] ファイルが無いときは、横一列、中、比率なしとする
- [x] 比率の記憶が無いあいだは、サムネイル領域を現在のサイズの 1 行分にし、残りを大プレビューにする
- [x] ズーム倍率とページ内の表示位置は、このファイルへ書かない
- [x] 前回の読み込みフォルダと保存フォルダは、この計画では保存しない
- [x] 設定の取得と保存は、画面の HTML 以外の既存 API と同じく、トークンの `Authorization: Bearer` を要求する
- [x] トークンが無いときは、設定の取得と保存を拒否する
- [x] 読み込み中、ダイアログ中、書き出し中でも、設定の取得と保存は拒否しない
- [x] 設定の取得と保存は、編集状態、選択、Undo を変えない
- [x] `GET /api/settings` は保存済みの設定を返す
- [x] ファイルが無い、読めない、または `thumbnail_layout`、`thumbnail_size`、`pane_ratio` のいずれかが欠けるときは、欠けた項目だけ既定にする
- [x] 既定は `thumbnail_layout: "row"`（横一列）、`thumbnail_size: "medium"`（中）、`pane_ratio: null`（比率なし）である
- [x] 壊れたファイルでも起動と GET は続ける
- [x] `PUT /api/settings` の本体は、`thumbnail_layout`、`thumbnail_size`、`pane_ratio` の 3 キーをすべて持つ
- [x] `thumbnail_layout` は `"row"` または `"grid"`（複数列）である
- [x] `thumbnail_size` は `"small"`（枠の高さ 96px）、`"medium"`（150px）、`"large"`（220px）である
- [x] `pane_ratio` は null、または 0 より大きく 1 未満の有限数である。これはサムネイル領域の高さ /（大プレビューの高さ + サムネイル領域の高さ）である
- [x] `PUT /api/settings` の成功は 200 で、保存後の同じ本体を返す
- [x] 未知の方式やサイズ、範囲外の `pane_ratio`、キー不足は 400 とし、ファイルを変えない
- [x] 保存先の既定は `%LOCALAPPDATA%\pdf-editor\settings.json` である
- [x] 生成時にパスを差し替えられるようにし、自動テストは一時ディレクトリを渡してファイルの中身を確認する

設定 API を [アーキテクチャの API 一覧](../../architecture.md#編集状態) へ足す作業は、「同期タスク」にある。

### 確認

- [x] 小 / 中 / 大を切り替え、再起動後も同じサイズになる
- [x] 横一列 / 複数列を切り替え、再起動後も同じ方式になる
- [x] 境界をドラッグした比率が、再起動後も残る
- [x] 設定ファイルが無い起動は、横一列、中、1 行分のサムネイル領域になる
- [x] 見えていないサムネイルにキャンバスが無い
- [x] 長辺 400px を超えるキャンバスを作らない

## フェーズ4: ズームと表示位置

### 実装

- [x] 表示モードは、ページ全体、幅に合わせる、100% とする
- [x] 初期はページ全体である
- [x] +/- と Ctrl+ホイールの段階は、25、50、75、100、125、150、175、200、225、250、275、300、325、350、375、400% である
- [x] ページ全体の倍率が 25% 未満のときは、その倍率のまま表示する
- [x] ページ全体の倍率が 25% 未満のとき、段階へ移るのは + を押したときだけで、そのとき 25% になる
- [x] ページ全体、幅に合わせる、100% から +/- したときは、名前付きの表示モードを離れ、隣の段階へ移る
- [x] 実効倍率が段階のあいだにあるときは、+ はより大きい隣の段階、- はより小さい隣の段階である
- [x] 下限は 25%、上限は 400% で、25% の - と 400% の + は変化しない
- [x] 実効倍率が 25% 未満の名前付きモードでは、+ だけが名前付きモードを離れて 25% にする
- [x] 実効倍率が 25% 未満の名前付きモードでは、- は名前付きモードと、その 25% 未満の倍率を維持する
- [x] 拡大時は、スクロールバーとドラッグでパンする
- [x] ページを切り替えても、倍率、表示モード、ページ内の相対位置を可能な限り維持する
- [x] 全画面プレビューは無い
- [x] ズームは次回起動へ持ち越さない
- [x] 無効なボタンは、理由と使える条件をツールチップで示す

### 確認

- [x] 初期がページ全体である
- [x] +/- が 25% 刻みである
- [x] +/- は 25% 未満と 400% 超へ行かない
- [x] ページ全体の倍率が 25% 未満の PDF では、+/- の前までその倍率のままである
- [x] ページ全体の倍率が 25% 未満の PDF では、+ のあとだけ 25% になる
- [x] ページ全体の倍率が 25% 未満の PDF では、- を押しても 25% 未満のままである
- [x] ページを切り替えても、倍率とページ内の相対位置が維持される
- [x] 再起動後のズームは、ページ全体に戻っている

## 同期タスク

フェーズ1からフェーズ4の実装順とは別に、実装時に行う。仕様とアーキテクチャへの、選択の置き場所、ズームの段階、サムネイル寸法、設定ファイルのパスの反映は 2026-09-26 に行った。第1回レビューで計画に固定した次の契約は、実装時に同期セットへ足す。実ファイルは、このレビューの反復では更新しない。

- [x] [仕様のページを選び、見る](../../spec.md#ページを選び見る) の「複数選択中は、最後にクリックしたページである」を、次で置換する。複数選択中は、選択へ加えた最後のクリックのページである。選択から外したクリックは、それだけでアクティブページをそのページにしない。同じ節へ次も足す。Ctrl+クリックでページを加えたときは、そのページをアクティブページにする。選択済みでアクティブでないページを外したときは、アクティブページを維持する。アクティブページ自身を外し、選択が残るときは、見えている並びで後ろの最も近い残りの選択を新しいアクティブページにする。後ろが無ければ直前である。アクティブページが無い Shift+クリックは、そのページだけの選択にする。Shift+クリックの範囲は、その連続範囲だけを選択し、範囲外は外す
- [x] [CONTEXT.md](../../../CONTEXT.md) のアクティブページ「複数選択中は、最後にクリックしたページ」を、次で置換する。複数選択中は、選択へ加えた最後のクリックのページ。選択から外したクリックだけでは、そのページをアクティブにしない
- [x] 同じ節のズームへ、次を足す。実効倍率が 25% 未満の名前付きモードでは、+ だけが 25% へ移り、- はその倍率のままである。段階のあいだの実効倍率では、+ はより大きい隣の段階、- はより小さい隣の段階へ移る
- [x] [アーキテクチャの編集状態](../../architecture.md#編集状態) の API 一覧へ、次の 1 項を足す。選択と表示の計画が置く設定の口は、`GET /api/settings` と `PUT /api/settings` である。本体は `thumbnail_layout`（`row` または `grid`）、`thumbnail_size`（`small`、`medium`、`large`）、`pane_ratio`（0 より大きく 1 未満の数、または null）である。トークンを要求する。読み込み中、ダイアログ中、書き出し中でも拒否しない。編集状態と Undo は変えない
- [x] 実装後の実装状況の更新は、実装完了時に行う

## 対象範囲と対象外

対象:

- 見えているページの選択、アクティブページ、空のプレビュー、キーボード、ページジャンプ、件数
- サムネイルの方式とサイズ、解像度の上限、大プレビューの 3 枚キャッシュ
- ズームの 3 モードと 25% 刻み
- 境界のドラッグと、方式・サイズ・比率の記憶

対象外:

- 回転、削除、並べ替え、分割線、Undo / Redo、`POST /api/session/commands`
- 複数 PDF の末尾追加、ドラッグ＆ドロップでの読み込み、パスワード、電子署名
- 選択ページと分割の書き出し、未保存表示、設定ページ、ヘルプ、テーマ、通知
- 自動終了、トレイ、exe 化、編集タブを 1 つに制限すること
- 余白、アイコン、フォントサイズ、「...」の格納順、Edge / Chrome 以外の警告文
- 前回の保存先の記憶

## 合意済みの受け入れ条件

- 選択は見えているページが対象である。0 件があり得る。アクティブページは大プレビューの 1 枚であり、選択に含まれる。複数選択中、選択へ加えた最後のクリックはそのページをアクティブにする。Ctrl+クリックでアクティブページを外したあとの新しいアクティブページは、見えている並びで後ろの最も近い残りの選択、無ければ直前である
- 選択が 0 件のとき、プレビューは空で、前へ / 次へも矢印キーもページを選ばない
- アクティブページがあるときのページ移動は、移動先 1 ページだけの選択になる
- 読み込み完了後は 1 ページ目を選択する
- サムネイルの枠の高さは小 96px、中 150px、大 220px である
- ズームの段階は 25% から 400% まで 25 ポイント刻みである
- サムネイルの長辺は 400px まで、大プレビューのビットマップは最大 3 枚である
- 表示の記憶は `%LOCALAPPDATA%\pdf-editor\settings.json` である。ズームは次回へ持ち越さない
