## フェーズ1: 選択をセッションに載せる

編集状態の正本は Python バックエンドが持つ。選択はページの削除状態や回転には入れない。

### 実装

- [ ] `GET /api/session` の応答に `selected_page_ids` と `active_page_id` を加える。選択が 0 件のとき `active_page_id` は null である
- [ ] 読み込み成功時は、見えている 1 ページ目を選択し、それをアクティブページにする。作業領域を置き換えたときも同じである
- [ ] ページが 0 枚のときは、選択 0 件、アクティブページ無しである
- [ ] `PATCH /api/session/selection` を追加する。本体は `selected_page_ids` と `active_page_id` である。成功でセッションを返す
- [ ] アクティブページが選択に含まれない、見えていないページを含む、未知の識別子を含むときは 400 とし、セッションを変えない
- [ ] 読み込み中、ダイアログ中、書き出し中の PATCH は 409 とし、セッションを変えない
- [ ] この PATCH は Undo の履歴を作らない。履歴そのものは次の計画である
- [ ] トークンの無い PATCH は拒否する
- [ ] `tests/test_session.py` に、上記の成功と失敗を足す

### 確認

- [ ] 読み込み直後のセッションは、1 ページ目だけを選択し、そのページがアクティブである
- [ ] 空の選択を PATCH すると、アクティブページは null である
- [ ] 不正な識別子では、直前の選択が残る
- [ ] 書き出し中の PATCH は 409 であり、選択は変わらない

## フェーズ2: 選択の画面

フェーズ1のセッションを、サムネイルと大プレビューに反映する。回転と削除のボタンは置かない。

### 実装

- [ ] 単一クリックは、そのページだけの選択にし、アクティブページにする
- [ ] Ctrl+クリックは、そのページの選択を反転する。残った選択の最後にクリックしたページをアクティブページにする。選択が 0 件になったときはアクティブページを無くす
- [ ] Shift+クリックは、アクティブページからそのページまでの連続範囲を選択する。クリックしたページをアクティブページにする
- [ ] サムネイル一覧にフォーカスがあるときの Ctrl+A だけが、見えている全ページを選択する。アクティブページは、それまでのアクティブページが残るときそれを維持し、無ければ 1 ページ目にする
- [ ] 余白のクリック、または入力欄以外での Esc は、選択を 0 件にする
- [ ] 選択中のサムネイルは、枠または背景と、チェックマークで示す
- [ ] 選択が 0 件のとき、大プレビューは空で「ページを選択してください」と出す。前へ / 次へは無効である。← / → と Shift+矢印はページを選ばない
- [ ] アクティブページがあるときの前へ / 次へ、および ← / → は、複数選択を解除して移動先の 1 ページを選択する
- [ ] サムネイル一覧では ← / →、複数列では ↑ / ↓ でも、同じ移動をする
- [ ] Shift+矢印は、連続範囲を拡張または縮小する
- [ ] 入力欄にフォーカスがあるときは、その欄の標準の操作を優先する
- [ ] ページ番号の指定でジャンプできる。範囲外はエラーにする。Enter でも実行し、成功したら入力欄を空にする。ジャンプ先の 1 ページを選択する
- [ ] 画面に、総ページ数、選択ページ数、元 PDF 数を出す
- [ ] Tab で主要な要素へ移動でき、フォーカスを分かるように示す

### 確認

- [ ] ブラウザで、単一クリック、Ctrl+クリック、Shift+クリック、Ctrl+A、余白クリック、Esc を確認する
- [ ] 選択 0 件のプレビュー文言と、前へ / 次への無効を確認する
- [ ] 複数選択中の前へ / 次へが、移動先 1 ページだけの選択になることを確認する
- [ ] 範囲外のページ番号がエラーになり、選択は変わらないことを確認する

## フェーズ3: サムネイルの並びと、表示の記憶

### 実装

- [ ] サムネイルは「横一列と横スクロール」と「複数列と縦スクロール」を切り替える
- [ ] 枠の高さは小 96px、中 150px、大 220px とする。幅はページの縦横比に合わせる
- [ ] 各サムネイルに、現在ページ番号、元 PDF 名、元ページ番号を示す。長い名前は省略し、ホバーで全文を出す。フルパスは出さない
- [ ] 右クリックメニューと、ダブルクリックの特別な動作は無い
- [ ] 横一列では、通常のホイールで左右にスクロールする
- [ ] 見えていないサムネイルにはキャンバスを作らない
- [ ] サムネイルのキャンバスは、表示枠の CSS ピクセルに devicePixelRatio を掛けて描く。長辺の上限は 400px である
- [ ] 大プレビューのビットマップは、現在のページと前後 1 ページの最大 3 枚まで保持する
- [ ] プレビューとサムネイルの境界をドラッグで調整する。最低高さは、大プレビュー 240px、サムネイル領域 160px である
- [ ] 設定ファイルは `%LOCALAPPDATA%\pdf-editor\settings.json` とし、バックエンドが読み書きする。ブラウザの localStorage は使わない
- [ ] 保存するのは、サムネイルの方式、サイズ、領域比率だけである。ファイルが無いときは、横一列、中、比率なしとする
- [ ] 比率の記憶が無いあいだは、サムネイル領域を現在のサイズの 1 行分にし、残りを大プレビューにする
- [ ] ズーム倍率とページ内の表示位置は、このファイルへ書かない
- [ ] 前回の読み込みフォルダと保存フォルダは、この計画では保存しない
- [ ] 設定の取得と保存の API を置き、トークンを要求する。自動テストは、一時ディレクトリへパスを差し替えてファイルの中身を確認する

### 確認

- [ ] 小 / 中 / 大と、横一列 / 複数列を切り替え、再起動後も同じ方式とサイズになる
- [ ] 境界をドラッグした比率が、再起動後も残る
- [ ] 設定ファイルが無い起動は、横一列、中、1 行分のサムネイル領域になる
- [ ] 見えていないサムネイルにキャンバスが無い
- [ ] 長辺 400px を超えるキャンバスを作らない

## フェーズ4: ズームと表示位置

### 実装

- [ ] 表示モードは、ページ全体、幅に合わせる、100% とする。初期はページ全体である
- [ ] +/- と Ctrl+ホイールの段階は、25、50、75、100、125、150、175、200、225、250、275、300、325、350、375、400% である
- [ ] ページ全体の倍率が 25% 未満のときは、その倍率のまま表示する。+/- で段階へ移ったときだけ 25% 以上にする
- [ ] ページ全体、幅に合わせる、100% から +/- したときは、名前付きの表示モードを離れ、隣の段階へ移る
- [ ] 拡大時は、スクロールバーとドラッグでパンする
- [ ] ページを切り替えても、倍率、表示モード、ページ内の相対位置を可能な限り維持する
- [ ] 全画面プレビューは無い。ズームは次回起動へ持ち越さない
- [ ] 無効なボタンは、理由と使える条件をツールチップで示す

### 確認

- [ ] 初期がページ全体である
- [ ] +/- が 25% 刻みで、25% 未満と 400% 超へ行かない
- [ ] ページ全体の倍率が 25% 未満の PDF では、+/- の前までその倍率のままである
- [ ] ページを切り替えても、倍率とページ内の相対位置が維持される
- [ ] 再起動後のズームは、ページ全体に戻っている

## 対象範囲と対象外

対象:

- 見えているページの選択、アクティブページ、空のプレビュー、キーボード、ページジャンプ、件数
- サムネイルの方式とサイズ、解像度の上限、大プレビューの 3 枚キャッシュ
- ズームの 3 モードと 25% 刻み
- 境界のドラッグと、方式・サイズ・比率の記憶

対象外:

- 回転、削除、並べ替え、分割線、Undo / Redo、`POST /api/session/commands`
- 複数 PDF の末尾追加、ドラッグ＆ドロップでの読み込み、パスワード、電子署名
- 選択ページと分割の書き出し、未保存表示、設定ページ、ヘルプ、テーマ、通知
- 自動終了、トレイ、exe 化、編集タブを 1 つに制限すること
- 余白、アイコン、フォントサイズ、「...」の格納順、Edge / Chrome 以外の警告文
- 前回の保存先の記憶

## 合意済みの受け入れ条件

- 選択は見えているページが対象である。0 件があり得る。アクティブページは大プレビューの 1 枚であり、複数選択中は最後にクリックしたページである
- 選択が 0 件のとき、プレビューは空で、前へ / 次へも矢印キーもページを選ばない
- アクティブページがあるときのページ移動は、移動先 1 ページだけの選択になる
- 読み込み完了後は 1 ページ目を選択する
- サムネイルの枠の高さは小 96px、中 150px、大 220px である
- ズームの段階は 25% から 400% まで 25 ポイント刻みである
- サムネイルの長辺は 400px まで、大プレビューのビットマップは最大 3 枚である
- 表示の記憶は `%LOCALAPPDATA%\pdf-editor\settings.json` である。ズームは次回へ持ち越さない
