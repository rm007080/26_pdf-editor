# トレイと exe 計画レビュー記録

## 第1回（計画 v1 → v2）

- P0: 1 / P1: 5 / P2: 3
- 計画版: v2
- 担当: サブエージェント計画レビュー（generalPurpose / inherit）

### 指摘と対応

| 重大度 | 指摘 | 対応 |
| --- | --- | --- |
| P0 | 編集権タブがあるトレイ終了の完了手順（`exit_requested` → 画面確認 → 停止またはキャンセル）がどの計画のタスクにも無い | ✅ v2。対象に確認画面を含め、`POST /api/shutdown` と `POST /api/session/exit-cancel` の分岐と受け入れを書いた |
| P1 | 受け入れはトークンを終了時に消すのに、段階1が「終了時に残る」になっていた | ✅ v2。チェックを「終了時に残らず」に直した |
| P1 | `session.token` と `app.state.token` の同一性が書いていない | ✅ v2。ファイルには `app.state.token` だけを書き、別トークンは作らない |
| P1 | タブ無しの停止を `POST /api/shutdown` にすると編集権必須で 409 になる | ✅ v2。確認不要とタブ無しはプロセス内の `session.shutdown`。タブありの実行だけ `POST /api/shutdown` |
| P1 | 凍結時の `web/dist` 探索が無い | ✅ v2。`sys.frozen` のとき `sys._MEIPASS` 配下。spec の同梱位置も同じ |
| P1 | exe が完成版の `PDF_EDITOR_ENV=production` にならない | ✅ v2。凍結かつ未設定のときだけ `production`。`python -m app` は開発版のまま |
| P2 | 2回目起動が失敗でも終了コード 0 になりうる | ✅ v2。成功だけ 0。失敗は 1 と「既に起動している画面を開けなかったため終了します。」 |
| P2 | トレイからプロセスを止める手段が無い | ✅ v2。一時データを消し、トレイを消し、`uvicorn.Server.should_exit` を立てる |
| P2 | `python -m app` でもトレイとミューテックスを持つか未記載 | ✅ v2。exe と同じ `main`。別入口は作らない |

反映時の追加: アーキテクチャの単一インスタンスの文の置換文を同期状況へ書いた。実ファイルはレビューのループ中は変えない。

- P0: 1 / P1: 2 / P2: 0
- 計画版: v3
- 担当: サブエージェント計画レビュー（generalPurpose / inherit）

### 指摘と対応

| 重大度 | 指摘 | 対応 |
| --- | --- | --- |
| P0 | `POST /api/editor/open` が 6 番目の編集権 409 の例外に入っておらず、タブ閉鎖後の「開く」が 409 になりうる | ✅ v3。Bearer のみ・編集権不要・409 対象外と明記。実装時に 6 番目の例外リストへ揃える。アーキテクチャ置換文にも同じ旨 |

| P1 | 段階1と画面確認が「未保存」だけを条件にしている | ✅ v3。`unsaved` または `split_unexported`。両方偽なら確認しない。画面確認はそれぞれの単独も含む |
