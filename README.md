# PDF 編集

Windows 上で、手元の PDF のページ構成を組み替え、元のファイルを変えずに新しい PDF として書き出すローカルアプリです。画面はブラウザ、編集状態の正本は Python バックエンドです。待ち受けは `127.0.0.1:8765` だけで、他の PC からは使えません。

製品全体の要求は [docs/spec.md](docs/spec.md) にあります。この README は、いまリポジトリから起動して使える範囲を書きます。

## いまできること

- PDF を 1 つ選んで読み込む。次に選ぶと、作業領域はその PDF に置き換わる
- サムネイルと大プレビューでページを見る
- ページを選ぶ。クリック、Ctrl+クリック、Shift+クリック
- ズーム（ページ全体、幅に合わせる、100%、25% から 400% まで 25 ポイント刻み）
- サムネイルを横一列または複数列にし、サイズを小 / 中 / 大にする
- 選択したページ、またはサムネイル上の 1 ページを、90 度ずつ回転する、削除する
- サムネイルのドラッグ、またはページ番号を指定して、前または後へ並べ替える
- 元に戻す、やり直す（Ctrl+Z / Ctrl+Y）
- 見えている全ページを 1 つの PDF として書き出す。保存ダイアログ、書き出し後の「PDF を開く」「保存先を開く」はバックエンドが Windows へ依頼する

読み込んだ PDF は Windows の一時フォルダへコピーし、以後はそのコピーを使います。元のファイルはロックしません。

パスワード付き PDF は、この画面では開けません。複数 PDF の結合、ファイルのドラッグ＆ドロップ、分割線、選択ページだけの書き出し、ヘルプ、システムトレイ、exe 配布は、まだこの起動経路にはありません。

## 必要なもの

- Windows
- Python 3.11 以上
- Node.js（画面の組み立てだけに使う。アプリの起動後は使わない）
- ブラウザは Microsoft Edge または Google Chrome

依存の版は [pyproject.toml](pyproject.toml) と [web/package.json](web/package.json) に固定しています。採用理由は [docs/tech-stack.md](docs/tech-stack.md) にあります。

## セットアップ

リポジトリのルートで実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

画面を組み立てます。成果物は `web/dist` に出ます。このディレクトリは Git に含まれないので、起動の前に必ず組み立ててください。

```powershell
cd web
npm install
npm run build
cd ..
```

## 起動

```powershell
python -m app
```

`http://127.0.0.1:8765/` を既定のブラウザで開きます。ポート 8765 がすでに使われているときは、メッセージを出して終了します。止めるときは、起動した端末で Ctrl+C を押します。終了時に、この起動で作った一時コピーを消します。

`PDF_EDITOR_ENV` を未設定のまま、または `development` にすると、同じオリジンの `/docs` に API ドキュメントが出ます。`development` 以外にすると、このドキュメントは出ません。

## 使い方

1. 「PDF を選ぶ」で PDF を開く。読み込みが終わると 1 ページ目が選ばれる。
2. サムネイルでページを選ぶ。余白のクリック、または Esc で選択を解除する。選択が 0 件のとき、大プレビューは「ページを選択してください」になる。
3. 「左回転」「右回転」「削除」は、選んでいるページ全体に効く。サムネイル上の回転と削除は、その 1 ページだけに効く。
4. サムネイルをドラッグして並べ替える。移動先のページ番号を入れて「その前へ」または「その後へ」でも移動できる。
5. 「前へ」「次へ」、または ← / → で、移動先の 1 ページだけを選ぶ。ページ番号を入れて「移動」すると、そのページへ跳ぶ。
6. 「全ページを書き出す」を押す。保存ダイアログで保存先を決めると、進捗が表示される。見えているページが 0 枚のときは書き出せない。

サムネイルの並び、サイズ、プレビューとサムネイルの高さの比率は `%LOCALAPPDATA%\pdf-editor\settings.json` に保存され、次の起動でも残ります。ズームは持ち越しません。

## テスト

リポジトリのルートで、API と編集状態と書き出しを確認します。

```powershell
python -m pytest
```

画面の型チェックと組み立ては、`web` で `npm run build` です。
